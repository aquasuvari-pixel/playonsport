How it works

Approved event flow

🏐⚽🏀🏸
1
Venue manager adds free time
Admin checks and approves the slot.
2
Registered user creates an event
The selected slot is held until admin approval.
3
First instruction is published
The event becomes visible and participants join.
4
Roster completes and final instruction is sent
Participants, admin and venue manager receive final details.
48-hour rule: All approvals and final arrangements must be completed at least 48 hours before venue use.
